1. Understand the financing problem

Your question: can public support make an $80M private loan acceptable to its lender?

A renewable infrastructure project costs USD 100 million: $20M sponsor equity plus an $80M private loan. A separate $20M public budget can fund a guarantee reserve, an interest subsidy or a preparation grant. The reserve is committed cash capacity; only a loan loss triggers its payout.

All dollar figures below are USD millions (M). Default probabilities apply over one illustrative project period. Ignore interest and discounting. Losses are positive amounts. The stated $60M/$70M losses already refer to the loan after sponsor equity; do not subtract the sponsor's $20M again.

Given scenario inputs

The guarantee absorbs the first loan losses up to its cap. Subsidies support debt service; grants support project preparation. In this teaching model their effects on default probability and loan loss are held fixed, so only the guarantee changes the lender's loss. In practice those other channels can matter.

Example: trace the loan loss

Allocate $12M to the guarantee G, $5M to subsidy S and $3M to grant H. Budget used = G + S + H = 12 + 5 + 3 = $20M.

  1. If default occurs: public payout = min(D, G) = min(60, 12) = $12M; private loss = max(D − G, 0) = 60 − 12 = $48M. Together they absorb $60M.
  2. Before uncertainty resolves: expected private loss = p × private loss in default = 0.10 × 48 = $4.80M. With no default (90% probability), both losses are zero. Expected public payout = 0.10 × 12 = $1.20M.
  3. As a percentage of the loan: 100 × 4.80 / 80 = 6.00%. This exceeds 2.00%, so the lender declines.
  4. Protection needed: allowed expected loss = 0.02 × 80 = $1.60M. Allowed loss in default = 1.60 / 0.10 = $16M. G must be at least 60 − 16 = $44M.
  5. Actual mobilization: committed private loan / public support = 0 / 20 = 0×. The ratio 80 / 20 = 4× applies only if that loan actually closes.

Display money and rates to two decimals; keep full precision in calculations. A minimum guarantee rounded to cents of a million must be rounded up if ordinary rounding would leave it below the threshold.

Next decision: moving support to the guarantee lowers expected private loss, but $44M exceeds the budget. A useful recommendation can be to redesign the project or decline it.

3. Decide how to use public support

Choose up to $20M in each case. Each control is a dollar amount, not a percentage. Keep the baseline and stress allocations the same to isolate the effect of the risk change, or adjust stress deliberately and use the comparison table to separate the two effects.

Baseline

p = 10%; default loan loss = $60M; loss-rate limit = 2%.

Stress

p = 15%; default loan loss = $70M; loss-rate limit = 2.5%.

A 10% to 15% probability change is 5 percentage points, or a 50% relative increase. The stress loss rises by $10M; the lender also relaxes its limit by 0.5 percentage points.

Optional extension — public junior capital replaces private debt

This is the separate lecture model: $100M project = J public junior capital + (100 − J) private senior capital. There is no separate sponsor-equity tranche or external guarantee in this extension. Default destroys $60M/$70M of project value. The target is 2% in both cases.

Expected senior loss rate = 100 × p × max(D − J, 0) / (100 − J).

For a 2% target and J below D: p(D − J) ≤ 0.02(100 − J), so J ≥ (pD − 2) / (p − 0.02). Baseline: (6 − 2)/(0.10 − 0.02) = $50M. Stress: (10.5 − 2)/(0.15 − 0.02) = $65.384615M (at least $65.39M if using two decimals). These differ from $44M/$56.67M in the game because the senior principal changes, and the game's stress limit is 2.5%.

Try once: at J = 50, baseline expected loss is $1M on $50M senior capital, exactly 2%.

Hint and full working

Use the remaining senior capital as the denominator. 100 × 0.10 × (60 − 50) / (100 − 50) = 2%. Increasing J lowers both senior loss and senior principal.
